# ICON TICKETS

A responsive web-based ticketing and event management interface built with HTML, CSS and JavaScript.

## Overview

ICON TICKETS is a front-end ticketing platform concept that provides an interface for discovering events, managing event information and interacting with ticket-related functionality.

The project was developed with a focus on responsive design, clear user interfaces, client-side functionality and practical web application workflows.

## Features

- Responsive event catalogue
- Event details and ticket information
- Event creation and management interface
- Admin dashboard
- Image upload functionality
- Ticket-related workflows
- Client-side data handling
- Responsive layouts for desktop and mobile screens
- Interactive JavaScript components
- Deployment-ready static build

## Technologies

- **HTML5** — page structure and semantic markup
- **CSS3** — responsive layouts and styling
- **JavaScript** — application logic and interactivity
- **Browser APIs** — client-side functionality and storage
